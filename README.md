SnapGrid
SnapGrid is a modern social media platform where users can connect, share posts, follow people, interact with content, and communicate through real-time messaging.

Features
- User registration and login
- JWT-based authentication
- User profiles
- Create and share posts
- Like and comment on posts
- Follow and unfollow users
- Notifications
- Real-time messaging
- Image uploads
- Responsive and modern UI

Tech Stack
Frontend
- React.js
- Tailwind CSS
- React Router
- Socket.io Client

Backend
- Node.js
- Express.js
- Sequelize ORM
- MySQL
- JWT
- Socket.io
